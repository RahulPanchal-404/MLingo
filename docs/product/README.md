# Product notes

# Product vision

MLingo makes machine learning inspectable: **Machine Learning, Frame by Frame.** The product is for students and demonstrators who need to see how a model changes, not only whether the final metric looks good.

## Core experience

Every lab follows the same mental model: configure an experiment, run it, inspect the visualization, select a frame, connect it to math and code, review diagnostics, and scrub the timeline. Linear Regression uses MSE, Logistic Regression uses Binary Cross-Entropy, and K-Means uses Inertia.

## Current scope
 
The product includes three labs (Linear Regression, Logistic Regression, K-Means), synchronized timelines, diagnostics, deterministic Training Insights, Comparison Insights, Math Mode, Code Mode across all algorithms, Break Mode challenges, Experiments workspace, Learn curriculum, and browser-local Progress. It intentionally excludes accounts, payments, AI tutoring, leaderboards, and additional algorithms. Training runs are not yet durable across sessions.
 
## Demo path
 
Landing page -> Learn -> Gradient Descent -> scrub timeline -> diagnostics & Training Insights -> Math Mode -> Code Mode -> Break Mode -> Logistic Regression -> K-Means -> Comparison -> Experiments -> Progress.
